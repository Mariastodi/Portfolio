IronID

Do cadastro
à próxima entrada.

Uma aplicação para gerenciar alunos, planos e presença em academia. Desenvolvi este projeto de estudo para aprofundar a construção de APIs em PHP, a organização de regras de negócio e a integração com um front-end responsivo.

PHPBackend

API REST

Laravel e Sanctum para autenticação. Endpoints para alunos, planos, renovação e histórico de acessos.

IDExperiência

Identificação facial

O navegador extrai o descritor facial. A API compara os vetores e retorna o nome e a matrícula do aluno cadastrado.

✓Qualidade

Regras testadas

Planos vencidos não registram entrada. Leituras repetidas em até um minuto reutilizam o check-in. Validação com PHPUnit.

Arquitetura

Responsabilidades claras.

Form Requests validam entradas, controllers coordenam HTTP, serviços aplicam regras e Resources definem as respostas JSON.

Aprendizado e próximos passos

Construir, testar
e conhecer os limites.

A aplicação foi testada em SQLite. O laboratório separado de SQL Server inclui View, Stored Procedure, Function, Trigger e permissões, ainda sem execução em instância real. O reconhecimento é um protótipo assistido pela recepção, sem prova de vida ou uso como controle físico autônomo.

O código do IronID está disponível no GitHub, com instruções de instalação, documentação da API, testes automatizados e decisões de arquitetura.
